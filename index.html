DramaCuts Uploader

DramaCuts Uploader is a local, single-user command-line tool. It lets the owner of the YouTube channel upload video files from their own computer to their own channel using the YouTube Data API v3.

The application has no public sign-up, no backend server, no database, and no analytics. It is used only by the channel owner on their own machine. All videos and OAuth credentials stay on that machine.
